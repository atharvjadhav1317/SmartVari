# Contributing to SmartVari

- Work on focused modules and keep changes within the relevant area.
- Avoid modifying another team member's module without coordination.
- Never commit secrets, credentials, API keys, or deployment tokens.
- Use environment variables for configuration and sensitive values.
- Make small, focused commits with clear messages.
- Explain architectural changes in the pull request or commit description.
- Test changes before committing.
- Do not fabricate official Wari or government data.
- Clearly label synthetic, demo, or sample data.
- Keep human oversight in place for AI-assisted decisions and recommendations.

During the foundation phase, do not add application workflows or features unless the team has agreed that the repository is moving into implementation.
